# Social Drawing Platform API

REST API сервіс для соціальної платформи спільного малювання.

## Основний функціонал

* Реєстрація та автентифікація (JWT)
* Створення малюнків з шарами
* Додавання шарів до малюнків (своїх та чужих)
* Лайки малюнків
* Підписка на користувачів
* Персоналізована стрічка малюнків

## Технології

* Python 3.14
* FastAPI
* SQLAlchemy (SQLite)
* Pydantic V2
* Passlib (PBKDF2)
* Pytest

## Запуск з Docker

Для запуску системи за допомогою Docker:

1. Побудуйте та запустіть контейнер:
   ```bash
   docker-compose up --build
   ```

3. Веб-інтерфейс буде доступний за адресою: `http://localhost:8000/`
4. Документація API буде доступна за адресою: `http://localhost:8000/docs`

## Запуск локально (без Docker)

1. Встановіть залежності:
   ```bash
   pip install fastapi uvicorn sqlalchemy pydantic[email] python-jose[cryptography] passlib python-multipart pytest httpx
   ```

2. Запустіть сервер:
   ```bash
   uvicorn app.main:app --reload
   ```

3. Веб-інтерфейс буде доступний за адресою: `http://127.0.0.1:8000/`
4. Документація API буде доступна за адресою: `http://127.0.0.1:8000/docs`

## Юзкейси

### 1. Реєстрація та вхід
`POST /auth/register` — Створення нового акаунта.
`POST /auth/login` — Отримання JWT токена.

### 2. Робота з малюнками
`POST /drawings/` — Створення нового малюнка (потрібен заголовок `Authorization: Bearer <token>`).
`GET /drawings/{id}` — Перегляд малюнка та всіх його шарів (сортування за часом створення).
`POST /drawings/{id}/layers` — Додавання нового шару.
`DELETE /drawings/{id}` — Видалення малюнка (тільки власником).

### 3. Соціальні взаємодії
`POST /drawings/{id}/like` — Лайк малюнка (один раз на користувача).
`POST /drawings/users/{id}/follow` — Підписка на користувача.
`GET /drawings/feed` — Стрічка малюнків від користувачів, на яких ви підписані.

## Бізнес-правила

* Порядок шарів визначається часом створення.
* Тільки власник може видалити малюнок.
* Не можна підписатись на самого себе.
* Не можна лайкнути один малюнок двічі.
